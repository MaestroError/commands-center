| Run enforcement locally                                      | Missing                                  | `CONTRIBUTING.md` and the canonical guide   |
| Apply mandatory agent rules                                  | One broad theme instruction              | `AGENTS.md`, linked to canonical docs       |
| Understand installed frontend technologies                   | AGENTS listed absent assistant-ui/SVAR   | AGENTS stack table and root README          |
