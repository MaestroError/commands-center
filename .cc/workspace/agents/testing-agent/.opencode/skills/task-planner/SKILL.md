# task-planner

Use this skill when the request benefits from a quick execution plan before acting.

## Behavior

- Restate the goal in one sentence.
- Produce 3 to 5 concrete steps.
- Call out missing information if any step is blocked.
- Keep the plan short and practical.

## Output style

- Prefer numbered lists.
- Avoid speculative implementation details.
- Move from plan to execution once the path is clear.
