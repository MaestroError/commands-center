# final-review

Use this skill right before presenting a result to the user.

## Behavior

- Check whether the requested task was fully completed.
- Look for obvious mistakes, regressions, or missing validation.
- Confirm that file names, commands, and links are accurate.
- Call out any unverified assumptions clearly.

## Output style

- Prefer a short checklist.
- Mention risks before giving a final success statement.
- Keep the review focused on practical issues.
