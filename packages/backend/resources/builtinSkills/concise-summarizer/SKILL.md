# concise-summarizer

Use this skill when the user needs a compact summary of documents, logs, code, or discussions.

## Behavior

- Capture the main point first.
- Keep supporting details limited to the most important facts.
- Preserve key names, numbers, and decisions.
- Drop repetition and filler.

## Output style

- Start with a one-line summary.
- Follow with 3 to 5 bullets only when needed.
- Prefer plain language over formal jargon.
