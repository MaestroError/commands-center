# Profile

## Purpose

Profile is the small personalization screen for the single user of CommandsCenter. It should let the user manage basic personal preferences that affect how the app identifies and presents their local operator context.

## Functional Description

- Show the user's basic personal settings in one small screen.
- Let the user set or update a display name.
- Let the user choose a timezone.
- Keep profile scope intentionally limited in MVP.

## User Stories

- As a single user, I want to set a display name, so that the app can reflect my preferred operator identity.
- As a single user, I want to choose my timezone, so that time-based information can be presented relative to my local context.
- As a single user, I want profile settings to stay small and separate from system configuration, so that personal preferences do not get mixed with broader app settings.
