# Profile

## Purpose

Profile is the personalization screen for the single user of CommandsCenter. It should let the user manage personal preferences that affect how the app identifies and presents their local operator context.

## Functional Description

- Show the user's personal settings in one screen.
- Let the user set or update a display name.
- Let the user choose a timezone.
- Let the user choose the active application theme.
- Keep profile scope focused on personal preferences in MVP, with room for additional personalization post-MVP.

## User Stories

- As a single user, I want to set a display name, so that the app can reflect my preferred operator identity.
- As a single user, I want to choose my timezone, so that time-based information can be presented relative to my local context.
- As a single user, I want to choose the app theme from my profile, so that I can use the visual mode I prefer.
- As a single user, I want profile settings to stay separate from system configuration, so that personal preferences do not get mixed with broader app settings.
