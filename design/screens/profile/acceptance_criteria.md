# Profile Acceptance Criteria

- Selecting the profile entry or profile access point from the app header opens the profile screen.
- The profile screen shows inputs for display name, timezone, and theme selection.
- When the user saves a display name, the system persists that display name.
- When the user saves a timezone, the system persists that timezone.
- The profile screen provides theme selection.
- When the user selects a theme and saves or applies it, the selected theme becomes the active application theme.
- When the user reopens the app after changing the theme, the previously selected theme remains active.
- If the user reopens the profile screen after saving changes, the saved display name, timezone, and theme selection are shown.
