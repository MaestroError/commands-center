# Built-in Skills Acceptance Criteria

- Selecting the built-in skills entry in navigation opens the built-in skills screen.
- The built-in skills screen shows all available skills from the curated library when one or more skills exist.
- If no built-in skills are available, the screen shows an empty state.
- Each skill shown on the built-in skills screen displays the skill's name, description, and any relevant metadata such as category or version.
- The user can select a skill to view its full details, including what files or capabilities it provides.
- Built-in skills shown on this screen are available for selection from the create or edit agent screen.
- When a built-in skill is assigned to an agent through the create or edit agent screen, the system copies the skill's files into that agent's workspace folder.
- The copied skill files become part of the agent's portable workspace and persist with the workspace across restarts and moves.
- The built-in skills library is saved as part of the project repository.
