# Global Terminal Acceptance Criteria

- Selecting the global terminal entry in navigation opens the global terminal screen.
- The global terminal screen provides the same terminal interaction behavior as the terminal used inside direct chat.
- The global terminal runs commands in the global or host environment rather than in a single agent workspace.
- The global terminal uses the main page area as a dedicated terminal workspace instead of a small docked panel.
- The global terminal supports multiple terminal sessions as tabs.
- When the user creates a new terminal session, the screen opens that session as a new terminal tab.
- When the user switches between terminal tabs, the screen shows the selected terminal session.
- On mobile-sized layouts, the global terminal preserves the same terminal session workflow in a full-screen mobile presentation.
