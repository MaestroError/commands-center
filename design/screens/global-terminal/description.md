# Global Terminal

## Purpose

Global Terminal is the fullscreen terminal screen for host-level command work in CommandsCenter. It should give the single operator the same terminal experience used inside direct chat, but in a dedicated full-page workspace outside any single agent.

## Functional Description

- Provide the same terminal interaction model used by the direct chat terminal.
- Run commands at the host or global machine scope rather than inside one agent workspace.
- Use a fullscreen terminal workspace for longer or broader command-line tasks.
- Support multiple terminal sessions as tabs.

## User Stories

- As a single user, I want a fullscreen terminal screen, so that I can work on longer command-line tasks outside the chat layout.
- As a single user, I want the global terminal to behave like the direct chat terminal, so that I do not have to learn a different terminal workflow.
- As a single user, I want to run commands at the host level, so that I can install tools and perform machine-wide operations.
- As a single user, I want multiple terminal sessions in one place, so that I can switch between parallel command-line tasks.
