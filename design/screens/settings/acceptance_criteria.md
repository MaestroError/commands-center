# Settings Acceptance Criteria

- Selecting the settings entry in navigation or the settings quick action from dashboard opens the settings screen.
- The settings screen shows the global runtime or workspace-related settings exposed by the app.
- When the user changes a supported setting and saves it, the system persists the updated setting.
- The settings screen provides theme selection.
- When the user selects a theme and saves or applies it, the selected theme becomes the active application theme.
- When the user reopens the app after changing the theme, the previously selected theme remains active.
- The settings screen shows the current application version.
- When an update check result is available, the settings screen shows whether an update is available.
- If an update is available and the current installation mode supports self-update, the settings screen provides an action to start the update flow.
- If the current installation mode does not support self-update, the settings screen shows update guidance instead of a self-update action.
