# Settings

## Purpose

Settings is the app-wide configuration screen for CommandsCenter. It should let the single operator manage runtime preferences, workspace-related configuration, theme selection, and update actions from one global place.

## Functional Description

- Show global application configuration in one screen.
- Let the user review and update runtime or workspace-related settings exposed by the app.
- Let the user choose the active application theme.
- Show the current application version and whether an update is available.
- Provide the update action and related update guidance in the same screen rather than in a separate update page.

## User Stories

- As a single user, I want one place for global app configuration, so that I can manage how CommandsCenter behaves without searching through feature screens.
- As a single user, I want to review and change runtime or workspace-related settings, so that I can adapt the app to my environment and workflow.
- As a single user, I want to choose the app theme in Settings, so that I can use the visual mode I prefer.
- As a single user, I want to see the current version and update state in Settings, so that I can decide whether to update the app.
- As a single user, I want to start the update flow from Settings, so that app maintenance is handled from the main configuration screen.
