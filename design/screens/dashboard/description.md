# Dashboard

## Purpose

Dashboard is the main landing screen for the single user of CommandsCenter. It should give a fast, useful overview of the current workspace state and help the user jump into active work without extra navigation.

## Functional Description

- Show high-level system state in one place, including the health of the app and its core services.
- Surface the most relevant recent activity, especially recent agents.
- Surface the latest automation sessions so the user can quickly understand what recently ran and what needs attention.
- Expose important operational signals such as update availability and major sync/runtime status.
- Provide quick entry points into the most common next actions.

## User Stories

- As a single user, I want to see the current health of the application when I open the app so that I can immediately know whether the system is ready for work.
- As a single user, I want to see my recent agents so that I can quickly continue the work I was doing before.
- As a single user, I want to see the latest automation sessions so that I can notice recent runs, failures, or activity without opening the automations screen first.
- As a single user, I want to see whether an update is available so that I can decide when to update the application.
- As a single user, I want direct access to common next actions from the dashboard so that I can move into chat, automations, files, or settings with minimal friction.
