# Dashboard Acceptance Criteria

- When the user opens the application, the dashboard is shown as the default landing screen.
- The dashboard shows a recent agents section that lists agents ordered by most recent direct-message activity when recent agent activity exists, shows an empty state when no recent agent activity exists, allows the user to open an agent's direct chat, and includes an action to navigate to the full agents screen.
- The dashboard shows a latest automation sessions section that lists automation sessions ordered by most recent execution time when automation session history exists, shows an empty state when no automation session history exists, displays the automation identity, execution status, and execution time for each listed session, and allows the user to open the related automation view.
- The dashboard shows system state for the application runtime, OpenCode engine, database mode, and automation system.
- The dashboard shows update state, including the running version and whether an update is available, and when an update is available it provides an action that navigates to the update flow in settings.
- The dashboard shows quick actions for creating an agent, opening automations, opening file manager, and opening settings, and each quick action opens the corresponding screen or workflow.
